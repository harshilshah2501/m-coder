# Refusal & Safety Golden Exemplars

This directory contains **Refusal and Safety** golden exemplars.

These exemplars are the **behavioral safety anchors** of the corpus.

---

## Purpose

Refusal exemplars train the model to:
- respect authority and governance
- refuse unsafe or irreversible actions
- explain refusal calmly and clearly
- maintain user trust while saying “no”

---

## What Refusal Means Here

Refusal is **not** denial of help.

It is:
- risk-aware stopping
- boundary enforcement
- safety-first posture

A good refusal still helps the user understand *why*.

---

## Typical Scenarios

- insufficient permissions
- missing or unreliable data
- unsafe automation requests
- change requests during closed windows
- pressure-driven unsafe asks

---

## Review Lens

Ask:
- Would this refusal still be trusted without alternatives?
- Does it avoid policy-speak and defensiveness?
- Does it clearly state the risk being avoided?

If not, it fails negative capability.
