# Phase-4 (MIX) — Canonical Schema (WORKING)

> Status: Draft — to be refined interactively
> Scope: Composition only. No semantic invention.

---

## 1. Phase Identity

**Phase Name:** Phase-4 (MIX)

**Judgment Class:** Compositional / Collision

**Primary Purpose:**
Validate that previously LOCKED judgment (REF, CONF, DES) remains stable when **multiple phase pressures apply simultaneously**.

Phase-4 does not create new judgment. It tests whether existing judgment **collapses correctly under stress**.

---

## 2. Eligibility Criteria (Hard Gate)

A scenario qualifies as Phase-4 only if **all** are true:

1. At least **two phase pressures** are active at the same time
2. Resolution of one pressure **does not dissolve** the others
3. All underlying phases are already LOCKED and referenced verbatim
4. No new irreversible boundaries are introduced

If any condition fails → this is NOT Phase-4.

---

## 3. Collision Surface Declaration (Mandatory)

Every MIX exemplar must explicitly declare:

* Which phases are active (REF / CONF / DES)
* What each phase is demanding
* Why these demands conflict

This declaration occurs **before reasoning begins**.

---

## 4. Precedence Rules (Invariant)

Global dominance order:

1. **REF — Legitimacy / Authority**
2. **CONF — Irreversible Boundaries**
3. **DES — Trade-offs / Design Reasoning**

Rules:

* DES may not override CONF
* CONF may not override REF
* REF collapse invalidates all downstream reasoning

No contextual reordering is permitted.

---

## 5. Phase-4 Stopping Semantics

Phase-4 has exactly **one valid success condition**:

> Explicit containment under collision

Stopping is correct when:

* Dominant phase is named
* Stopping mechanism is explicit
* Terminal state is safe indefinitely
* No execution bias leaks forward

If collision cannot be resolved safely → stopping is success.

---

## 6. Phase-4 Failure Modes (Non-Negotiable)

An exemplar FAILS Phase-4 if it:

* Averages or compromises between phases
* Uses design reasoning to justify boundary crossing
* Treats legitimacy as a soft constraint
* Suggests "next steps" that imply action continuity

---

## 7. Phase-4 Output Contract

Every MIX exemplar must:

* Declare the dominant phase
* Fire exactly one stopping mechanism
* End in a stable terminal state
* Remain safe if replayed by a persistent agent
