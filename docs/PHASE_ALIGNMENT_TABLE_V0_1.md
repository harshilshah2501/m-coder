## Gate Flow

1. **Plan gate:** Resolves phase; builds plan object
2. **Authority validator:** Verdict pass/fail/unknown
3. **Irreversibility detector:** Boundary position (pre vs cross)
4. **Execute/ledger:** Terminal posture; ledger row emit
5. **Observation:** Drift baselines; collapse tracking; reconciliation; GREG

## Notes

- Stage-6 (mutation) ≠ Constitutional Phase-6 (REACH)
- Constitutional phases define *how judgment must behave*
- Compilation stages define *workflow steps*
- Runtime gates implement Phase-05 (CODE) semantics
