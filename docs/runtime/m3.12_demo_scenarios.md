# M3.12 Demo scenarios — Repo-aware ask

Curated scenarios for the near-production vertical slice demo. Same repo + same query → same selected bundle.

---

## Scenario 1: Context selection

**Query:** "How does context selection work?"

**Expected behavior:** Manifest includes `docs/runtime/REPOSITORY_CONTEXT_ENGINE.md` and `runtime/context/selectors.py`. Selection may include them by path_match or heading_match. Response is PLAN_ONLY with selection_reason per file and a short note in plan_summary.notes (e.g. "Repo-aware selection: N file(s) by path_match, heading_match.").

**Expected bundle shape:** context_bundle.files[].path in [docs/..., runtime/context/...], each with selection_reason; plan_summary.steps (3–6 steps); governance_posture "PLAN_ONLY"; execution false.

---

## Scenario 2: Repository context engine doc

**Query:** "Where is the repository context engine documented?"

**Expected behavior:** Path or heading match on "repository", "context", "engine" selects docs and possibly runtime/context modules. Same query twice → same files list.

---

## Scenario 3: Plan-Gate

**Query:** "How does Plan-Gate work?"

**Expected behavior:** Selection may include docs/runtime and runtime/plangate or plan_gate_service paths if in ingestion config. PLAN_ONLY response; no execution.

---

## Golden output shape

- schema_version: plan_only_response.v0.1
- context_bundle.revision, context_bundle.files[].path, context_bundle.files[].selection_reason
- plan_summary.steps (array of strings)
- plan_summary.notes (optional, for repo-aware explanation)
- governance_posture: "PLAN_ONLY"
- execution: false
